Preguntas individuales de salida

1. ¿Qué diferencia existe entre guardar, hacer commit y hacer push?
Guardar solo actualiza el archivo en el directorio local, el commit ya registra y 
guarda los cambios en el git local y el push ya sube los commits al repositorio remoto en github.

2. ¿Qué cambia cuando un compañero fusiona su PR? ¿Qué debes hacer en tu computadora?
Cuando un compañero fusiona su PR, sus cambios pasan a main. En mi computadora debo hacer 
git pull para descargarlos.

3. ¿Qué requisito verifica tu prueba y qué comportamiento incorrecto detectaría?
Mis pruebas verifican que las etiquetas repetidas se eliminen sin cambiar su orden y que 
el promedio se calcule correctamente. Detectarían etiquetas desordenadas o un promedio incorrecto.

4. ¿Por qué una prueba nueva que pasa inmediatamente puede ser útil?
Porque confirma que la función ya cumplía el requisito y evita que cambios futuros dañen 
ese comportamiento.
